# Salary Prediction with Linear Regression in Python — scikit-learn Train and Predict Example

A beginner-friendly **machine learning** example in Python: a scikit-learn **linear regression** pipeline that predicts salary from years of experience, with a separate training script that saves the model and scaler with `joblib`, and an inference script that loads them to make predictions.

## Overview

This project has two scripts:

- **`Model Builder/builder.py`** — cleans data, trains the model, evaluates it, and saves it to disk
- **`Prediction/prediction.py`** — loads the saved model and predicts salary from user input

## Scripts

### Model Builder (`builder.py`)

A complete ML pipeline that processes a CSV dataset and produces a trained model.

#### Pipeline Steps

| Step | Action |
|---|---|
| 1 | Load dataset from `Source/Salary.csv` |
| 2 | Remove duplicate rows |
| 3 | Drop columns with >50% missing values; fill remaining nulls with column mean |
| 4 | Scale `years_experience` using `StandardScaler` |
| 5 | Split into 80% train / 20% test sets |
| 6 | Train `LinearRegression` model |
| 7 | Evaluate with R² score and Mean Squared Error |
| 8 | Save model and scaler if R² > 0.95 |

#### Usage

Both scripts open files with paths relative to the working directory (`./Source/...`), so run them from the `Salary` folder:

```bash
python "Model Builder/builder.py"
```

**Output format:**
```text
R² Score: <score to 4 decimal places>
Mean Squared Error: <mse to 2 decimal places>
Model and scaler saved!
```

If R² ≤ 0.95, the model is not saved and `Model not saved as R² score is below 95%.` is printed instead.

---

### Salary Predictor (`prediction.py`)

Loads the saved model and scaler, accepts user input, and outputs a predicted salary.

#### Usage

From the `Salary` folder:

```bash
python "Prediction/prediction.py"
```

**Session format:**
```text
Enter Years of Experience: 7
Predicted Salary for 7.0 years of experience: $<predicted amount>
```

## Notes

- A trained `salary.pkl` and `scaler.pkl` are already included, so `prediction.py` works without training first. Run `builder.py` to retrain them. If your scikit-learn version differs from the one that created the files, retraining avoids version-mismatch warnings when loading them.
- The dataset must contain `years_experience` and `salary` columns.
- The model is only saved when the test-set R² exceeds 0.95. This is a demo's save condition, not a guarantee of prediction quality on new data.
- The current script fills missing values and fits its scaler before the train/test split. For an independent evaluation, split first and fit preprocessing only on the training data, then transform the held-out data with those fitted steps. The current order allows held-out data to influence preprocessing.
